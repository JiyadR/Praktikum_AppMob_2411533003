### **Data Flow:**

1. **App Start** → SplashScreen → check session
   - Session exists → MainScreen (auto-login)
   - No session → LoginScreen

2. **Register** → hash password → save to DB → save session → MainScreen

3. **Login** → verify password → save session → MainScreen

4. **Dashboard** → fetch user transactions → calculate balance → display

5. **Add Transaction** → validate form → save to DB → pop back → refresh

6. **History** → fetch all user transactions → display list

7. **Profile** → display user info → logout → clear session → LoginScreen

### **Database Schema:**
```sql
CREATE TABLE users (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  email TEXT UNIQUE NOT NULL,
  passwordHash TEXT NOT NULL,
  name TEXT NOT NULL,
  createdAt TEXT NOT NULL
);

CREATE TABLE transactions (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  userId INTEGER NOT NULL,
  title TEXT NOT NULL,
  amount REAL NOT NULL,
  category TEXT NOT NULL,
  date TEXT NOT NULL,
  createdAt TEXT NOT NULL,
  FOREIGN KEY (userId) REFERENCES users(id) ON DELETE CASCADE
);
```
